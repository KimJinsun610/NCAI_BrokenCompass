3. 조우 배정과 카드 충돌

최초 조우 S-A만 첫날 과학실에 고정한다. 실제 관찰 전 다른 공간 모형은 숨긴다. 나머지 H-A·H-B·C-A·C-B·T-A·T-B·S-B의 순서를 회차 시작에 한 번 섞고 저장한다. 둘째 날부터 첫 일반 점검 완료 후 미관찰·도달 가능·비가시 준비 가능 후보를 고른다. 오늘 미방문 공간과 직전 조우와 다른 공간을 우선하며, 후보가 없으면 이 두 선호만 차례로 완화한다. 실제 금지·봉쇄 조건은 완화하지 않는다. 현재 공간은 준비를 위해 우선 제외하고, 모두 불가능하면 다음 공간 이동에 재검사한다.

선정한 장면은 잠그고 새로 뽑지 않는다. 준비 위치를 보고 있으면 대기한다. 최초 조우 이후에는 배치 50 같은 수치가 등장 허가를 결정하지 않는다. 3축은 기존 구간별 소리·빛·배치 변화를 담당한다. 날짜별 공간 순서를 고정하거나 새 확률을 도입하지 않는다.

미관찰 모형은 같은 자리에 남기고, 관찰 후 퇴실·비가시 상태에서 정리한다. 모형은 회차당 장면별 한 번 소비한다. 관찰하지 않은 채 떠난 장면을 소비하지 않는다. 다음 날로 넘기려면 오늘 조우 관찰·방문 종료가 필요하다. 다른 공간 모형을 동시에 노출하지 않는다. 의도적 미관찰에 강제 시선·체류 즉사를 추가하지 않는다.

7. 이번 정리에서 달라진 부분

  • H2·C3는 순간적인 고개 돌리기와 3초 응시를 구분하도록 플레이어 문구를 수정했다. S5는 빈 보관 위치가 아닌 발견한 모형을 접근 금지 대상으로 명시했다.
  • T3는 칸을 닫고 다시 열지 않은 채 화장실 밖으로 나가는 순서를 명시하고, 닫기 전 퇴실·재개방의 누락 판정을 보완했다.
  • 보완안: H4·T6를 근무 종료까지 감시하도록 문장과 정산 시점을 통일했다. P2·P4 때문에 같은 카드를 다시 채점하거나 준수를 취소하는 구현을 막기 위한 변경이다.
  • C5·S6의 손전등 유지 종료를 문구에 명시했다. C6은 기존 밤 종료 판정에 맞춰 ‘나올 때’ 대신 ‘근무 종료 전까지’ 닫도록 바꿨다.
  • 보완안: C1은 구간표에서 세 획이 유지되는 0~49에서만 발동한다. 실제로 셀 수 없는 소리를 세 획 위반 조건으로 쓰지 않는다. P3는 순서만 바꾸도록 ‘1-3 제외’ 표현을 고쳐 C6의 전체 점검 의무와 충돌하지 않게 했다.
  • H-A의 이미 열린 문, H-B의 기존 장기 금지, 모형 효과음과 카드 단서의 구분을 장면 요약에도 반영했다. 교실 책상 수·과학실 실험대 수 증감 설명은 현재 표의 고정 개수에 맞췄다.
  • 새 공지·카드·모형·문자는 추가하지 않았다. 원본의 24·8·12개 구성과 각 축 델타를 유지했다. 조우 순서 무작위화, 3축 경고, 100 종료도 유지한다.

확정 상태: 카드별 동작·종료·예외 명세 작성 완료. 보완안의 수치와 씬 대상 연결은 구현 시 확인 필요. Unity 기능·자산 확인 및 플레이테스트 필요. 포획 엔딩은 종료 신호 이후 연출 명세가 별도로 필요하다.
