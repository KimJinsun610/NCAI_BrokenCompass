## 함정 (밟지 말 것)

- `Assets/_Game/Scripts/Editor/`는 `NightDuty.Editor` asmdef 안이라 **Assembly-CSharp을 못 본다**. `SpaceZones`·`SpaceLights`를 건드리는 에디터 스크립트는 반드시 `Assets/_Game/Flow/Editor/`에 둔다.
- 근무 공간의 등은 **Realtime**이어야 한다. 라이팅을 다시 구우면서 Mixed로 되돌리면 "Band4 = 전 공간 소등"이 안 된다.
- `Assets/NOT_Lonely/`는 gitignore 대상. 참조 금지, `git add` 금지.
- C# 9만 사용 (파일 범위 namespace·record·global using 금지).
- 씬을 고쳤으면 `save_scene`을 반드시 호출한다. eval로 바꾼 값은 저장 전까지 디스크에 없다.
- Unity MCP 호출이 60초 타임아웃으로 실패해도 대개 작업은 들어간 상태다. 재시도 전에 상태를 먼저 읽는다.
- 에디터 창이 뒤에 있으면 플레이 모드 프레임이 진행되지 않는다. 플레이 검증은 사용자가 창을 앞에 두고 해야 한다.
- ponytail 모드는 "가장 단순한 해법"을 강제한다. **기획 정본을 정확히 따라야 하는 판정 코어에는 적용하지 않는다.**
