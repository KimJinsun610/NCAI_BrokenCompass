# 화장실 — 오디오 사용처

폴더: `audio_final/toilet/` · 파일 8개

뒤에 `_Hear75`, `_Hear90`이 붙은 파일은 그 청각 구간 전용 합본이다. 앞 구간 소리에 그 구간에서 추가되는 소리가 이미 붙어 있으므로, 합본을 쓰는 구간에서는 기본형을 함께 재생하지 않는다.

## 청각 구간별로 재생하는 것

| 청각 구간 | 재생 |
|---|---|
| 0~24 | 소리 파일 없음. 기본 환경음 |
| 25~49 | A18 안쪽 칸 물 내림 1회 |
| 50~74 | A18 + **A19 세면대 배관 두드림**(별도 방문). 기존 "근무자님" 호칭을 대체 |
| 75~89 | **A20 합본**(물 내림 + 끝에 칸 내부 손잡이 소리). A18은 재생하지 않는다 |
| 90~99 | **A21 합본**(물 내림 + 닫힌 칸 위치의 들숨). 닫힌 칸이 없으면 들숨 생략 |

장면 전용음: A22(T-A 칸 문 닫은 직후), A23(T-B 출구 진입), A27·A28(칸 문 열림·닫힘, T1·T3).

## 손볼 곳과 정할 것

- 호칭이 두드림으로 바뀌었으므로 T4 수칙, P21 문자, 화장실 이상현상표 50~74, 자기 신고 문장에서 "호칭"이라고 쓴 곳을 함께 고쳐야 한다.
- 예전 호칭 파일은 `_unused/VO_TOILET_Call_근무자님호칭.wav`로 옮겨 두었다.
- **A18 `SFX_TOILET_Flush_Hear25.wav`**: T2 판정은 12초 시퀀스인데 파일은 8.87초다. 길이를 맞추거나 판정 시간을 조정할 것
- **A19 `SFX_TOILET_SinkKnock.wav`**: 두드림 5회(약 1.2초 간격)만 들어 있고 젖은 손 소리는 없다. T4·P21 문장을 호칭에서 두드림으로 바꿔야 한다
- **A20 `SFX_TOILET_Flush_Hear75.wav`**: 합본이라 같은 구간에서 A18을 함께 재생하지 않는다 / 파형이 최대치에 닿아 잘린 샘플이 553개 있어 지직거릴 수 있다. 2~3 dB 낮춰 다시 뽑는 편이 안전하다
- **A21 `SFX_TOILET_Flush_Hear90.wav`**: 합본. 닫힌 칸이 없는 날은 들숨 구간을 생략한다(원문 규칙)
- **A27 `SFX_TOILET_DoorOpen.wav`**: 음량이 낮다(-19.1 dB). 인게임에서 키울 것
- **A28 `SFX_TOILET_DoorClose.wav`**: 문이 다시 열리지 않으므로 1회만
