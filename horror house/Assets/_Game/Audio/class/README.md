# 교실 1-1·1-3 — 오디오 사용처

폴더: `audio_final/class/` · 파일 6개

뒤에 `_Hear75`, `_Hear90`이 붙은 파일은 그 청각 구간 전용 합본이다. 앞 구간 소리에 그 구간에서 추가되는 소리가 이미 붙어 있으므로, 합본을 쓰는 구간에서는 기본형을 함께 재생하지 않는다.

## 청각 구간별로 재생하는 것

| 청각 구간 | 재생 |
|---|---|
| 0~24 | A08 분필 한 획을 3회. 1-1 문밖, 하루 1회 |
| 25~49 | A08 유지 + A09 지우개 털기 1묶음 |
| 50~74 | A10 점검 후 퇴실 때 뒷줄 지정 책상 타격 1회 |
| 75~89 | **A11 + A12 동시**(칠판 긁기 + 교탁 의자 마찰음). 별도 방문의 입구에서 |
| 90~99 | A11 + A12, 칠판 소리가 끝난 뒤 교탁 마찰음(A12)을 한 구절 더 |

장면 전용음: A13(C-A 책상 타격), A11·A12(C-B 관찰·퇴실).

## 파일별 사용처

| A ID | 파일 | 언제 재생하나 | 길이 | 최대 음량 |
|---|---|---|---|---|
| A08 | `SFX_CLASS_ChalkStroke.wav` | 청각 0~24부터 계속: 1-1 문밖에서 분필 3획, 하루 1회. C1·P7 단서 | 2.86초 | -16.9 dB |
| A09 | `SFX_CLASS_EraserTap.wav` | 청각 25~49: 교실 안 지우개 털기 1묶음 | 4.16초 | -3.5 dB |
| A10 | `SFX_CLASS_DeskHit.wav` | 청각 50~74: 점검을 마치고 나가려 할 때 뒷줄 지정 책상 타격음 1회. C3 단서 | 4.65초 | -2.0 dB |
| A11 | `SFX_CLASS_BoardScratch.wav` | 청각 75~89: 별도 방문 입구의 칠판 긁기. C-B 관찰 때도 1회 | 5.30초 | -7.1 dB |
| A12 | `SFX_CLASS_TeacherChair.wav` | 청각 75~89: 칠판 소리와 겹치는 교탁 의자 마찰음. 청각 90~99: 칠판 소리가 끝난 뒤 한 구절 더. C-B 퇴실 때도 1회 | 6.45초 | -9.0 dB |
| A13 | `SFX_CLASS_DeskThump.wav` | C-A(문을 향한 좌석)에서 퇴실 준비 구역에 들어설 때 그 책상에서 둔한 타격 1회 | 2.93초 | 0.0 dB |

## 손볼 곳과 정할 것

- **A08 `SFX_CLASS_ChalkStroke.wav`**: 한 획 소스가 필요한데 여러 획이 들어 있고 음량도 낮다(-16.9 dB). 한 획만 잘라 3회 재생
- **A11 `SFX_CLASS_BoardScratch.wav`**: C4는 두 소리가 겹쳐야 성립한다. A12와 동시 재생
- **A13 `SFX_CLASS_DeskThump.wav`**: 타격이 3회 들어 있다. 1회분만 잘라 쓸 것 / 파형이 최대치에 닿아 잘린 샘플이 2811개 있어 지직거릴 수 있다. 2~3 dB 낮춰 다시 뽑는 편이 안전하다
