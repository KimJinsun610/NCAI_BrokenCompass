# 복도 — 오디오 사용처

폴더: `audio_final/hall/` · 파일 8개

뒤에 `_Hear75`, `_Hear90`이 붙은 파일은 그 청각 구간 전용 합본이다. 앞 구간 소리에 그 구간에서 추가되는 소리가 이미 붙어 있으므로, 합본을 쓰는 구간에서는 기본형을 함께 재생하지 않는다.

## 청각 구간별로 재생하는 것

| 청각 구간 | 재생 |
|---|---|
| 0~24 | 소리 파일 없음. 실제 문·발소리와 기본 환경음 |
| 25~49 | A02 앞쪽 지정 문 닫힘 1회 |
| 50~74 | A02 앞쪽 닫힘 뒤 지나온 문 닫힘 1회 |
| 75~89 | **A03 합본**(손잡이 놓는 소리 + 뒤쪽 문 닫힘). A02는 재생하지 않는다 |
| 90~99 | **A03-90 합본**(75 소리 + 뒤에서 뛰어오는 발소리가 바로 뒤에서 멈춤) |

장면 전용음: A05·A06·A07(H-A, H-B). 수칙 연동음: A01(H1), A04(H5).

## 파일별 사용처

| A ID | 파일 | 언제 재생하나 | 길이 | 최대 음량 |
|---|---|---|---|---|
| A01 | `SFX_HALL_DoorOpenSlow.wav` | 복도 통행 중 지정 문이 저절로 열릴 때. H1 단서이자 H-A에서 문이 닫혀 있을 때의 자동 개방 | 4.37초 | -2.0 dB |
| A02 | `SFX_HALL_DoorClose.wav` | 청각 25~49: 앞쪽 지정 문 닫힘 1회. 청각 50~74: 앞쪽 닫힘 뒤 지나온 문 닫힘 1회. H2 단서 | 3.58초 | -2.0 dB |
| A03 | `SFX_HALL_DoorClose_Hear75.wav` | 청각 75~89: 뒤쪽 문 닫힘. 손잡이 놓는 소리가 닫힘 앞에 붙어 있다 | 5.61초 | 0.0 dB |

| A06 | `SFX_HALL_LowKnock.wav` | H-B(상자 뒤 앉은 모형)를 발견한 순간 상자 위치에서 1회 | 8.88초 | -2.0 dB |
| A07 | `SFX_HALL_ChairDrag.wav` | H-B 구역을 벗어날 때 의자 위치에서 1회 | 5.34초 | -20.5 dB |

## 손볼 곳과 정할 것

- 90~99에 예전 명세의 "지정 문 무음 개방 1회"가 남아 있다. 소리가 없어서 파일은 필요 없지만, 뒤에서 뛰어오는 소리와 방향이 갈라지므로 유지할지 정해야 한다.
- 뛰어오는 소리에는 판정과 델타를 붙이지 않는다(H2 단서는 문 닫힘 소리 하나뿐). 하루 1회만 재생한다.
- **A02 `SFX_HALL_DoorClose.wav`**: 청각 75 이상에서는 A03·A03-90 합본으로 대체
- **A03 `SFX_HALL_DoorClose_Hear75.wav`**: 합본이라 같은 구간에서 A02를 함께 재생하지 않는다 / 파형이 최대치에 닿아 잘린 샘플이 525개 있어 지직거릴 수 있다. 2~3 dB 낮춰 다시 뽑는 편이 안전하다
- **A03-90 `SFX_HALL_DoorClose_Hear90.wav`**: 합본이라 문 소리와 발소리 사이 간격(약 0.6초)을 게임에서 조절할 수 없다. 발소리는 최대 약 -20 dB이고 문 소리는 -4 dB라 바로 뒤에서 멈추는 순간이 약하다. 마지막 걸음(8.6초) 뒤에도 10.7초까지 -38 dB 이하의 잔소리가 남아 완전한 정적이 아니다. 8.8초쯤에서 잘라 페이드아웃할 것 / 파형이 최대치에 닿아 잘린 샘플이 525개 있어 지직거릴 수 있다. 2~3 dB 낮춰 다시 뽑는 편이 안전하다
- **A06 `SFX_HALL_LowKnock.wav`**: 앞 0.5초에 두드림이 몰려 있고 뒤는 긴 꼬리다. 1회분만 잘라 쓸 것
- **A07 `SFX_HALL_ChairDrag.wav`**: 음량이 낮다(-20.5 dB). 인게임에서 키울 것
