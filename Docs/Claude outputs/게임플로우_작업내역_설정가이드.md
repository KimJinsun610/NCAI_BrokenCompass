## 전체 흐름

```
[Main] ─Start─▶ (Day 1로 초기화) ─▶ [Contract] 서명 → 출근하기 ─▶ [Loading] ─▶ [Play: testScene]
                                                    │  검은 화면 "Day n" → 페이드 아웃 → 게임 시작
                                                    │  12:00 → 6:00 (20배속, 현실 18분)
                                                    ├─ 사망 → 페이드 → 사망 화면(YOU DIED) ─ Restart ─▶ [Loading] ─▶ [Main]
                                                    │                                       └ Quit ─▶ 게임 종료
                                                    ▼  종료 시각 도달 (로딩 없이 바로)
                                               [Result]  ① 야간 근무 일지 (빨간 줄이 다 그어지면 확인)
                                                    │
        ┌──── Day 1~4 근무 완료 → 다음 날 (Day + 1) ──┤
        ▼                                            └── Day 5 근무 완료 → ② 수치 결산 → 메인으로 ─▶ [Loading] ─▶ [Main]
   [Loading] ─▶ [Play] … 반복
```

| 전환 | 로딩 씬 | 이유 |
|---|---|---|
| Main → Contract | **거치지 않음** | 계약서는 가벼운 UI 씬 |
| Contract → Play | 거침 | 무거운 Play 씬을 비동기로 불러옴 |
| Play → Result | **거치지 않음** | 결과창은 가벼운 UI 씬. 근무 종료 순간의 긴장감 유지 |
| Play(사망 화면) → Main | 거침 | 무거운 씬에서 나가면서 메모리 정리 |
| Result → Play / Main | 거침 | 다시 무거운 씬을 불러오면서 이전 씬 메모리 정리 |

# Part 1. 작업 내역

## 1-1. 로딩 씬 — 커밋 `ebc0120 Loading Scene Logic`

### 결정 사항
- 로딩 씬은 **목적지를 직접 정하지 않는 경유 씬 1개**로 만들고, 모든 전환에서 재사용합니다.
- 게이지가 100%가 되면 **키 입력 대기 없이 바로** 다음 씬으로 넘어갑니다.
- 일차 표시는 넣지 않습니다.
- 안내 문구는 **조작 안내만** 넣습니다. 규칙 해석이나 수치 힌트는 게임 설계상 넣지 않습니다.
- 씬은 이름이 아니라 **경로**로 지정합니다. `DemoScene.unity`처럼 같은 이름의 씬이 여러 폴더에 있기 때문입니다.

### 만든 것
| 파일 | 역할 |
|---|---|
| `02 Scripts/SceneFlow/SceneFlow.cs` | 씬 전환 진입점 (`SceneFlow.GoTo`) |
| `02 Scripts/SceneFlow/GameScene.cs` | 씬 종류 enum (Main / Loading / Play / Result) |
| `02 Scripts/SceneFlow/SceneFlowConfig.cs` | 씬 경로 표 ScriptableObject |
| `02 Scripts/SceneFlow/ScenePathAttribute.cs` | 인스펙터에서 씬을 드래그로 지정하게 하는 속성 |

- `HUDActions.cs`에 `StartGame()`을 추가했습니다.

### 검증

## 1-4. 결과창 → 야간 근무 일지 — 미커밋 (2026-09-15)

### 결정 사항
- 기획안 「일일 결산 — 근무 일지」를 반영해, 결과창을 **야간 근무 일지** 문서로 바꿨습니다.
  1. **문서 머리:** 근무일만 바뀌고, 근무 시간(12:00–06:00)과 순찰 지점(4곳)은 고정
  2. **금일 근무 지침:** 그날 받은 지침을 같은 순서로 보여 주고, **위반한 항목에만 빨간 줄**을 긋습니다. 준수한 항목과 조건이 안 걸린 항목은 똑같이 표시가 없습니다. 방문하지 않은 공간의 지침은 전부 빨간 줄입니다.
  3. **특이사항:** 입력란처럼 보이지만 편집할 수 없고, 5일 내내 "없음"
  4. **꼬리:** 면책 문구, 확인 버튼, 계약 잔여 일수. **확인은 빨간 줄이 다 그어진 뒤에만 눌립니다.**
- **이 화면에 넣지 않는 것:** 축 수치 · 막대 · 등급, 준수 체크 표시, 위반의 원인 · 결과 설명, 인체 모형 기록
- **수치 결산은 Day 5에만** 보여 줍니다. 흐름은 아래와 같습니다.
  | 상황 | 확인 버튼을 누르면 |
  |---|---|
  | Day 1~4 근무 완료 | 다음 날 Play (로딩 거침) |
  | 사망 (어느 날이든) | Day 1 Play (로딩 거침) |
  | Day 5 근무 완료 | 기존 수치 결산 화면 → 메인으로 |
- 지침 문구와 위반 여부는 판정 시스템이 없어서 **기획안 예시 8개 항목(4번 · 6번 위반)** 을 가짜 데이터로 넣었습니다.

## 1-5. 커서 · 결과창 페이드 · 폰트 정리 — 미커밋 (2026-09-15)

## 2-4. 게임 시간

**위치:** `03 Prefebs/03 System/PlaySystems` → `Game Time`

| 필드 | 현재 값 | 설명 |
|---|---|---|
| Start Hour / Start Minute | 0 / 0 | 시작 시각 (24시간 기준, 0 = 자정) |
| End Hour / End Minute | 6 / 0 | 종료 시각. 시작보다 이르거나 같으면 다음 날로 계산 (예: 23:00 → 1:00) |
| Time Multiplier | 20 | 현실 1초당 흐르는 게임 초. 20 = 20배속 |
| Use 12 Hour Format | 켜짐 | 켜면 `12:00` · `1:00`, 끄면 `00:00` · `01:00` |

- **현실 근무 길이 = (종료 − 시작) ÷ 배속.** 현재 360분 ÷ 20 = **18분**
  - 예: 6시간(0:00 → 6:00)을 현실 6분으로 하려면 Time Multiplier를 60으로
- 프리팹을 고치면 프리팹을 쓰는 모든 씬에 반영됩니다. 특정 씬만 다르게 하려면 그 씬에 배치된 인스턴스에서만 값을 바꾸세요.
- 시계는 Day 인트로가 끝난 순간부터 흐릅니다.

# Part 4. 알아둘 동작

- **일시정지하면 게임 시계도 멈춥니다.** `Time.deltaTime` 기준이라 `timeScale 0`에서는 흐르지 않습니다. 로딩 화면은 반대로 일시정지와 무관하게 진행됩니다.
- **Day 인트로 동안에는 게임 시계와 플레이어 조작이 멈춰 있습니다.** Esc 일시정지도 인트로가 끝난 뒤부터 동작합니다.
- **프레임이 크게 떨어지면 게임 시계가 느려집니다.** Unity가 한 프레임의 시간을 최대 약 0.33초로 자르기 때문입니다.
- **에디터 창을 최소화하면 Play가 거의 멈춥니다.** 프로젝트의 `Run In Background`가 꺼져 있습니다. 시간이나 전환을 테스트할 때는 창을 띄워 두세요.
- **결과창 커서:** 결과창에 들어오면 커서를 다시 보이게 합니다. Play의 `FPController`가 숨겨 둔 것을 복구하는 것입니다.
- **연타 방지:** 버튼 연타나 전환 중복 호출은 한 번만 처리됩니다.
- **폰트 파일 변경:** Pretendard는 쓰이는 글자를 그때그때 굽는 동적 폰트라, 한글이 화면에 처음 그려지면 폰트 파일에 글자와 텍스처가 저장되어 git 변경으로 잡힙니다. 빌드할 때 비워지는 설정이라 게임에는 영향이 없습니다.
  - 2048 텍스처가 저장되면 파일이 **8~12MB**까지 커집니다. 커밋 용량을 줄이려면 **커밋 직전에** `Tools > Programmer_Kim > Fonts > Clear Pretendard Dynamic Data`를 실행하세요 (9종 한 번에, 약 8KB로 돌아가고 실행하면 다시 채워집니다).
  - 비운 뒤에 Play하거나 한글 UI가 있는 씬을 열면 다시 채워져 파일이 커질 수 있습니다. 그래서 커밋 직전에 비우는 게 좋습니다.
  - 새 Pretendard 폰트 에셋을 만들면 `Tools > Programmer_Kim > Fonts > Apply Pretendard Dynamic Font Settings`를 실행하세요. 기본 설정(1024 · 90pt · Multi Atlas 꺼짐)으로는 한글이 금방 □로 깨집니다.
