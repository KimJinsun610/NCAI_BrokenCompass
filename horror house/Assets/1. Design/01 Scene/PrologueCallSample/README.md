# 야간근무 — 파견 전화 샘플

## 실행

`PrologueCallSample_hyun.unity`를 열고 Unity 상단 Play를 누르면 전화 연출이 자동 시작됩니다. 씬 내부 시작 버튼과 건너뛰기·다음 문장 기능은 없습니다. 에디터가 다른 창 뒤에 있으면 재생이 멈출 수 있으므로 Game 창을 선택한 상태에서 확인합니다.

전화벨 두 번과 수화음 이후, 시설관리팀 담당자가 폐교의 비품 반출·기존 근무자의 이탈·철거까지 남은 닷새·자정부터 여섯 시까지의 업무를 설명합니다. 자막은 하단에 한 문장씩 나타나며 음성 길이에 맞춰 자동 진행합니다. 통화 종료음과 문서 도착 자막을 보여준 뒤 2.5초 후 기존 `Assets/1. Design/01 Scene/ContractScene_hyun.unity`로 자동 이동합니다.

배경은 완전 검정입니다. 휴대전화 외형·발신자 표시·제목·장식은 표시하지 않으며, 중앙에 검정에 가까운 무채색 파형(#1A1A1A)만 남겼습니다. 파형은 전화벨 및 음성 출력 크기에 반응합니다. 기존 장식 오브젝트는 참조 보존을 위해 비활성으로 남아 있지만, 시작·건너뛰기·다음 문장 기능은 코드에서 제거했습니다.

## 범위와 연결

- 기존 메인 메뉴의 게임 플레이 버튼은 수정하지 않았습니다. 현재는 독립 샘플입니다.
- 계약서 씬·기존 스크립트·SceneFlow 설정·Build Settings는 수정하지 않았습니다.
- 계약서 씬이 현재 빌드 목록에 없으므로 에디터에서는 `LoadSceneAsyncInPlayMode`로 연결합니다. 빌드 배포용 연결은 하지 않았습니다. 빌드하려면 담당 개발자가 두 씬의 등록과 기존 메뉴 연결을 별도 검토해야 합니다.
- 계약서 진입 시 기존 메인 메뉴와 같은 `GameSession.StartNewRun()`을 호출합니다. 계약서의 서명과 출근 버튼 동작은 원래 코드를 그대로 사용합니다. 출근 이후의 실제 플레이 흐름은 이번 테스트 범위 밖입니다.
- 회사의 연구 목적과 이전 근무자의 출입 기록 문제는 통화에서 공개하지 않습니다.

## 파일과 소리

- `DispatchCallSample.cs`: 통화 자동 시작·하단 자막·계약서 자동 연결 코드입니다. Scene의 DispatchCallSample 컴포넌트에서 음성 클립을 교체할 수 있습니다.
- 원본 VARCO 음성은 `C:\Users\dnddl\OneDrive\Desktop\NC 팀플\audio_final\프롤로그\Call_01.mp3`부터 `Call_09.mp3`까지입니다. 문장 순서대로 이름을 정리했으며 원본 MP3 음성 데이터는 바꾸지 않았습니다.
- 전화벨은 `PhoneAudio/Phone_ring_3.wav`를 사용하고 클립이 끝난 뒤 짧은 간격을 두어 두 번 재생합니다. 수화기를 받는 순간과 통화 종료에는 같은 `PhoneAudio/Call_connect_1.wav`를 재사용합니다. 이 두 파일은 샘플의 `Resources/PhoneAudio` 폴더에서 불러옵니다.
- Unity 샘플은 `Voice/Call_01.wav`부터 `Call_09.wav`까지의 AudioClip 참조를 그대로 유지합니다. 원본 MP3를 44.1 kHz, mono, 16-bit PCM WAV로 변환해 WAV 데이터만 교체했습니다. 씬과 `.meta` GUID는 그대로라 재연결이 필요 없습니다.
- `Call_07`은 “자정부터 여섯 시까지”로 확정되어 TTS, 자막, 음성 생성 스크립트를 함께 맞췄습니다. 추가 글자 `여섯`은 샘플 전용 TMP 한글 글꼴 fallback에 추가했습니다.
- 연결된 Unity 에디터에서 9개 WAV가 AudioClip으로 다시 읽혔고 길이는 원본 MP3에 대응했습니다. 편집기 상태가 ContractScene_hyun의 일시정지 플레이였으므로, 그 세션을 중단하지 않고 새 음성으로 샘플 전체를 다시 재생하는 테스트는 하지 않았습니다.
- 문서 알림과 낮은 배경음은 코드에서 합성합니다. 배경음은 조용한 저음·회선 잡음이며 별도 작곡된 음악이나 실제 사무실 녹음은 아닙니다.
- 음성에는 전화 느낌의 저역·고역 필터가 적용됩니다. 음성·효과음·배경음은 각 AudioSource의 Volume으로 조절합니다.
- `DispatchCall_Korean.asset`과 `DispatchCall_Korean_Fallback.asset`: 샘플 전용 한글 글꼴입니다. 기존 글꼴 에셋은 수정하지 않았습니다.
- `Editor/DispatchCallSampleBuilder.cs`: 씬 최초 생성 도구입니다. 같은 이름의 씬이 있으면 덮어쓰지 않고 중단합니다.
- `GenerateVoice.ps1`: 임시 음성 생성 원본입니다. 기존 WAV가 있으면 덮어쓰지 않습니다.

## 미니멀 화면 수정 후 확인

- 컴파일 오류 없음. 별도 클릭 없이 Ringing에서 Talking으로 진행됨을 확인했습니다.
- 통화 중 활성 Button 수 0개, 배경 RGB(0,0,0), 파형 RGB(0.1,0.1,0.1), 하단 자막 배치와 넘침 없음을 확인했습니다.
- 화면은 `Preview_Minimal_Talking.png`로 확인했습니다. `Preview_Title.png` 등 이전 캡처는 수정 전 화면 기록입니다.
- 입력 없이 통화를 끝낸 뒤 ContractScene_hyun과 ContractController가 로드됨을 확인했습니다.
- 재생 시작 직후 CLI 명령이 한 번 시간 초과되어 에디터가 일시정지됐습니다. 재개 후 자동 진행을 검증했으며 이후 새 오류는 없었습니다. 프로젝트의 커서 텍스처 경고는 별도 설정 문제로 수정하지 않았습니다.
- 기존 파일 Git diff 해시와 계약서 씬·빌드 설정 해시는 수정 전과 동일했습니다.

## 최초 버전 확인 기록 (버튼 제거 전)

2026-09-28, Unity 6000.3.17f1의 연결된 에디터에서 확인했습니다.

- 스크립트 컴파일 완료, 컴파일 오류 없음.
- 게임 플레이 버튼 이벤트로 통화 시작, 연속 호출 시 중복 시작 차단 확인.
- 9개 문장이 자동 진행되어 마지막 문서 도착 상태에 도달함을 확인.
- 통화 중 CallerVoice와 QuietOfficeBed AudioSource의 재생 상태 확인. 생성 음성의 연기·자연스러움에 대한 청감 평가는 별도로 필요함.
- 제목·통화·문서 도착 화면 캡처 확인. 문서 도착 자막의 넘침 없음.
- 계약서 확인 버튼의 레이캐스트 및 포인터 클릭 이벤트를 실행하여 기존 ContractScene_hyun의 로드와 ContractController 존재 확인.
- 새 회차가 1일차로 초기화됨을 확인. 계약서의 출근 버튼은 누르지 않음.
- 통화 건너뛰기 후 문서 도착 상태, 음성 중지, 화면 페이드 해제 확인.
- 테스트 구간에 새 콘솔 오류 없음. 기존 파일 전체 Git diff 해시가 작업 전후 동일함. ContractScene_hyun과 EditorBuildSettings의 SHA256도 동일함.
- 실제 마우스·다양한 화면비·최종 빌드·최종 음량 믹싱은 별도 확인 필요.

## 구성 의도

평범한 파견 전화로 대체 근무의 사유를 먼저 설명하고, 플레이어가 계약서에서 결정하도록 분리했습니다. 화면 장식과 조작 버튼을 빼서 검은 화면의 음성과 하단 자막에 집중하도록 수정했습니다. 기존 게임 흐름 및 계약서 씬은 수정하지 않았습니다.
