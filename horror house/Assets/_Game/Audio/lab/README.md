# 과학실 — 오디오 사용처

폴더: `audio_final/lab/` · 파일 4개

뒤에 `_Hear75`, `_Hear90`이 붙은 파일은 그 청각 구간 전용 합본이다. 앞 구간 소리에 그 구간에서 추가되는 소리가 이미 붙어 있으므로, 합본을 쓰는 구간에서는 기본형을 함께 재생하지 않는다.

## 청각 구간별로 재생하는 것

| 청각 구간 | 재생 |
|---|---|
| 0~24 | A14 유효 점검 후 퇴실할 때 유리 파손음 1회 |
| 25~49 | A14 + A15 지정 유리 기구 접촉음 |
| 50~74 | A14 + A15 + A16 같은 책상의 짧은 긁힘 |
| 75~89 | 같은 구성. A15의 발생 위치만 책상 아래쪽으로 옮긴다 |
| 90~99 | A14 뒤에 A17 무거운 물체 놓는 소리 1회 |

장면 전용음: A15(S-B 관찰), A17(S-B 고청각 추가음). S-A에는 전용 소리가 없다.

## 파일별 사용처

| A ID | 파일 | 언제 재생하나 | 길이 | 최대 음량 |
|---|---|---|---|---|
| A14 | `SFX_LAB_GlassBreak.wav` | 점검을 마치고 과학실을 나온 직후 유리 파손음 1회. S2 발동과 P13 연결 | 3.44초 | -2.0 dB |
| A15 | `SFX_LAB_GlassClink.wav` | 청각 25~49부터: 지정 유리 기구 접촉음. S3·P14 단서, S-B 관찰 때 1회 | 7.97초 | -7.9 dB |
| A16 | `SFX_LAB_Scrape.wav` | 청각 50~74부터: 접촉음이 난 같은 책상에서 짧은 긁힘 추가 | 5.16초 | -4.9 dB |
| A17 | `SFX_LAB_HeavySet.wav` | 청각 90~99: 퇴실 파손음 뒤 무거운 물체 놓는 소리 1회. S-B 고청각 추가음 | 1.95초 | -2.0 dB |

## 손볼 곳과 정할 것

- **A14 `SFX_LAB_GlassBreak.wav`**: 퇴실 판정이 성립한 뒤에만 재생
- **A15 `SFX_LAB_GlassClink.wav`**: 청각 75~89에서는 같은 소리를 책상 아래쪽 위치에서 재생
